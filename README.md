# Sales Tax Calculator API for Shopify

A Shopify tax app integration for connecting a store to the Sales Tax Calculator API.

**Status: scaffold only. This app is not listed or ready to install.**

## Planned scope

- Connect a store to a Sales Tax Calculator API account.
- Map store, customer, and cart data to tax requests.
- Return the API result through Shopify’s supported tax app integration path.

Shopify tax app access and review requirements will be confirmed before implementation.
